Sitio web sobre agricultura y desarrollo rural
Esta declaración se aplica al contenido publicado en el dominio: https://agriculture.ec.europa.eu
No se aplica a otros contenidos o sitios web publicados en ninguno de sus subdominios. Estos sitios web y su contenido tendrán su propia declaración de accesibilidad específica.
Este sitio web está gestionado por la Dirección General de Agricultura y Desarrollo Rural. Está diseñado para ser utilizado por tantas personas como sea posible, incluidas las personas con discapacidades.
Usted debe ser capaz de:
- zoom hasta 200% sin problemas
- navegar por la mayor parte del sitio web usando solo un teclado
- navegue por la mayor parte del sitio web utilizando un lector de pantalla moderno y un software de reconocimiento de voz (en su computadora o teléfono)
Este sitio web está diseñado para cumplir con la norma técnica para sitios web y aplicaciones móviles, EN 301 549, v.3.2.1. Esto sigue de cerca el nivel «AA» de la versión 2.1 de las Directrices de Accesibilidad al Contenido Web (WCAG).
Estado de cumplimiento
Este sitio web cumple parcialmente la norma técnica EN 301 549 v.3.2.1 y las Directrices de Accesibilidad al Contenido Web (WCAG) 2.1 Nivel AA. Para más detalles, véase «Contenido no accesible».
El sitio web se probó por última vez en enero de 2025.
Preparación de la presente declaración
Esta declaración fue elaborada mediante una autoevaluación realizada por el organismo del sector público [véase el artículo 3, apartado 1, de la Decisión de Ejecución (UE) 2018/1523 de la Comisión].
La próxima revisión está programada para enero de 2026.

Compatibilidad con navegadores y tecnología de asistencia
El sitio web «Agricultura y desarrollo rural» está diseñado para ser compatible con las siguientes tecnologías asistenciales más utilizadas:
- la última versión de los navegadores Google Chrome, Microsoft Edge, Mozilla Firefox y Apple Safari;
- en combinación con las últimas versiones de NVDA, VoiceOver y TalkBack.
Especificaciones técnicas
La accesibilidad del sitio web «Agricultura y desarrollo rural» se basa en las siguientes tecnologías para trabajar con la combinación particular de navegador web y cualquier tecnología de asistencia o complementos instalados en su ordenador:
- HTML
- WAI-ARIA
- CSS
- JavaScript
- Formato de subtítulos: SRT (en inglés).
Contenido no accesible
A pesar de nuestros mejores esfuerzos para garantizar la accesibilidad del sitio web «Agricultura y desarrollo rural», somos conscientes de algunas limitaciones que estamos trabajando para solucionar. A continuación se muestra una descripción de las limitaciones conocidas y las posibles soluciones. Por favor, póngase en contacto con nosotros si se encuentra con un problema no enumerado a continuación.
Limitaciones conocidas del sitio web «Agricultura y desarrollo rural»:
- Muchos documentos son PDF y no son accesibles.
- Gráficos y gráficos: uso del color: Algunos gráficos y tablas en el sitio web se basan solo en el color para comunicar información, lo que es confuso para las personas con deficiencia de visión del color. En los gráficos en los que las etiquetas no están asociadas visualmente con la sección de color correspondiente, al hacer clic en las etiquetas de las leyendas se activa o desactiva la línea, barra o sección correspondiente, lo que permite a los usuarios comprobar qué etiqueta pertenece a qué parte del gráfico. Planeamos solucionar este problema en el transcurso de 2025.
- Enlaces externos abiertos sin previo aviso: Algunos enlaces abren una nueva ventana (o pestaña) sin previo aviso. Planeamos arreglar esto para fines de marzo de 2025.
- Subtítulos de vídeo: Algunos de nuestros videos no tienen subtítulos. Estamos trabajando continuamente para agregarlos a más videos.
- Reproductor de vídeo – Accesibilidad al teclado: Somos conscientes de algunos problemas con la accesibilidad del teclado de nuestro reproductor de video (al seleccionar el idioma de los subtítulos del menú, no es posible usar las teclas de flecha para moverse entre idiomas, esto solo se puede hacer con la tecla TAB).
- Descripción de audio: Los videos en este sitio web no tienen descripción de audio.
- Organigrama: La versión actual del organigrama visual publicado no es accesible para las personas que utilizan un lector de pantalla o los usuarios que dependen de la navegación por teclado. El Whoiswho es una alternativa accesible para la mayor parte de su contenido.
- La muestra de páginas web probadas con teclado solo funcionó bien. Continuaremos probando esta funcionalidad en el desarrollo continuo del sitio web.
