Accessibility statement
This statement:
- applies to content published on the domain: https://www.efsa.europa.eu
- does not apply to other content or websites published on EFSA subdomains with their own web addresses
The website www.efsa.europa.eu is managed by the European Food Safety Authority (EFSA). It is designed to be used by as many people as possible, including people with disabilities.
For example, you should be able to:
- zoom in up to 200% without encountering text spillover or other technical issues
- navigate most of the website using only a keyboard
- navigate most of the website using a modern screen reader and speech recognition software (on your computer or phone)
This website is designed to comply with the technical standard for websites and mobile apps, EN 301 549 v3.2.1, which is aligned with WCAG 2.1 level AA. Additional testing has been carried out against WCAG 2.2 level AA to support future accessibility requirements.
Compliance status
This website is partially compliant with the technical standard EN 301 549 v3.2.1 and the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA due to the issues listed in the Non-accessible content section below.
Feedback
Please email accessibility [at] efsa.europa.eu (accessibility[at]efsa[dot]europa[dot]eu) if you:
- encounter accessibility barriers on this website other than those listed in the Non-accessible content section below
and/or
- urgently need information that is currently unavailable in an accessible format
Be sure to specify the web page affected by the accessibility issue. We aim to respond to feedback within two working days.
Compatibility with browsers
This website is designed to be compatible with the most widely used browsers:
- Chrome
- Edge
- Firefox
- Safari
Technical specifications
The accessibility of this website relies on web technologies such as HTML, CSS and JavaScript, and works with a combination of web browsers and assistive technologies or plugins installed on your computer.
Non-accessible content
Despite our best efforts to ensure the accessibility of this website, we are aware of some limitations that we are working to resolve. Below is a description of known limitations. Please contact us if you encounter an issue that is not listed below.
Known limitations:
- Some elements do not use the proper ARIA attributes
- Some elements are not keyboard-accessible
- The programmatic level of some headings does not match their visual presentation and does not follow the correct hierarchy
- Some image text alternatives are uninformative or missing
