# Plan Operativo de la Campaña Agrícola 2026

Este documento establece las directrices operativas para la gestión de la campaña agrícola 2026 en todas las explotaciones gestionadas por AgroTech Iberia S.L. Toda la información contenida en este documento es de uso exclusivo del personal autorizado.

# 1. Objetivos

Durante la campaña 2026 se establecen los siguientes objetivos:

- Reducir el consumo de agua un 18%.
- Incrementar la producción de tomate industrial un 12%.
- Implantar sensores IoT en el 100% de las parcelas.
- Disminuir el uso de fertilizantes nitrogenados.
- Automatizar el sistema de riego en todas las fincas.

# 2. Parcelas afectadas

Las actuaciones se realizarán sobre las siguientes explotaciones:

- Finca Los Olivos (Sevilla)
- Finca El Campillo (Huelva)
- Finca Vega Sur (Córdoba)

Cada finca dispone de estaciones meteorológicas propias y sensores de humedad del suelo.







# 3. Cultivos

Los cultivos principales serán:

- Tomate industrial
- Maíz
- Trigo duro
- Olivar intensivo
- Almendro

El Departamento Agronómico será responsable del seguimiento semanal.

# 4. Tecnología implantada

La infraestructura tecnológica está formada por:

# Sensores

- Sensores de humedad SoilWatch X300
- Sensores de temperatura ClimateSense
- Sensores de conductividad eléctrica EC-Pro

# Drones

Modelo:

AgriDrone A900

Funciones:

- Fotografía multiespectral
- Detección de estrés hídrico
- Monitorización NDVI

# Plataforma

La plataforma SmartFarm Central recopila información de todos los sensores cada cinco minutos.

Los datos son almacenados en PostgreSQL y posteriormente procesados mediante modelos de Inteligencia Artificial.

# 5. Sistema de riego





# El riego está controlado mediante:

# Sistema:

Irrigation Manager 4.2

# Componentes:

- Electroválvulas Hunter
- Bombas Grundfos CR10
- Controladores Siemens LOGO!

# Las decisiones de riego se calculan utilizando:

- Humedad del suelo
- Predicción meteorológica
- Evapotranspiración diaria

# 13. Flujo de información

Los sensores envían datos a SmartFarm Central.

SmartFarm Central sincroniza la información con PostgreSQL.






# 14. Relaciones operativas

- El Departamento Agronómico supervisa los cultivos.
- SmartFarm Central procesa los datos de los sensores.
- Los sensores SoilWatch X300 monitorizan la humedad del suelo.
- AgriDrone A900 inspecciona las parcelas semanalmente.
- Irrigation Manager controla las electroválvulas Hunter.
- Fertiberia suministra fertilizante NPK 20-20-20.
- Yara suministra nitrato cálcico.
- John Deere 6155M realiza labores de preparación del terreno.
- El Proyecto Agricultura Inteligente 2030 coordina todas las iniciativas tecnológicas.
- PostgreSQL almacena toda la información agrícola.
- Los modelos de IA utilizan los datos almacenados para generar predicciones.
- El Departamento de Calidad verifica el cumplimiento de GLOBALG.A.P.
