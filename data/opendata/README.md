# Datos abiertos Canarias

Fuentes oficiales usadas por AgroPS:

- `registro_sat_canarias_2025.csv` — Registro de Sociedades Agrarias de Transformación (SAT).
- `diccionario_datos_registro_sat_canarias_2025.csv` — Diccionario de campos SAT.
- `dataset-ISTAC-*.xlsx` — Series ISTAC (exportaciones, precios, explotaciones).

Importación:

```bash
# autenticado como admin
POST /api/v1/opendata/import
```
